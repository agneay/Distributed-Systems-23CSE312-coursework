# Exercise 1 — Bidirectional Client–Server Chat

## Run
1. On Computer A, run `python server.py` (TCP port 5002).
2. On Computer B, run `python client.py` and enter Computer A's IPv4 address.
3. Both sides can type messages independently. Enter `/quit` to end.

## Concepts
TCP sockets, client–server architecture, bidirectional communication, concurrent receive thread.

## Network
Use the same LAN; allow port 5002 through firewall for private networks.
